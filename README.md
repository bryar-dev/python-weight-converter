Python Weight Converter

A simple Python program that converts weight between kilograms (kg) and pounds (lbs).

Features:

* Converts kg to lbs
* Converts lbs to kg
* Accepts decimal values
* Handles invalid unit inputs

How It Works:

The program asks the user to enter their weight and specify whether the weight is in kilograms or pounds.

It then uses the appropriate conversion formula and displays the converted weight.

Technologies Used:

* Python

1. Make sure Python is installed.

